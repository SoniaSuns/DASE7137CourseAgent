## WhatsApp 调用

1. 在已接入的 `DASE7137 - 2026` 或 `test approval` 群中，使用 WhatsApp 的真正 @ 提及选择 agent 账号，再写要求。
2. 例如：`@agent 请检查课程 A 的文件顺序与 syllabus 是否一致，先报告确定的不一致项。`
3. 涉及 Moodle 修改时，检查 Plan，再按消息原样回复 `OK <验证码>`；取消回复 `NO <验证码>`。回复当前问题或确认时无需再次 @。

可以通过 WhatsApp 的“文档”或“照片”发送附件，并在附件说明中真正 @agent 写明要求。Agent 将附件保存到当前任务的资料空间；照片交给配置的 Codex 模型看图，文档先按内容识别格式，再尝试文本或专用解析器，不能直接解析时继续使用分析工具。不会仅因扩展名不在列表中而拒绝读取。支持常用 Office、PDF、HTML、Unicode 文本、代码和 ZIP 内容检查。普通读文件请求直接回答；确实缺资料时在当前任务中询问，不生成 Moodle 的零操作报告。

等待你补充资料时，同一发送人可直接发送附件，无需再次 @。单个文件最多 32 MiB，每个任务最多 12 个文件、合计 128 MiB；图片解码最多 2500 万像素，动图仅查看首帧。不会自动抓取群历史附件。加密、损坏、特殊二进制、音视频及扫描 PDF 不保证能完整解析；会说明具体缺失，不能将“已接收”当作“已读懂”。

WhatsApp 使用管理员配置的课程和浏览器。需要操作自己的 Moodle，请使用下面的 Chrome 插件。

## Chrome 插件与现有 agent

1. 下载上方 ZIP 并解压；打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择解压目录。
2. 打开 **Moodle Workspace — My Browser** 侧栏。与管理员电脑连接同一局域网，服务地址填写 **`http://192.168.0.124:18791`**。
3. 点击“连接 agent”，即可进入此浏览器的工作区。
4. 在自己的 Chrome 登录 Moodle，打开课程主页，再点“连接当前 Moodle 课程”。可选择上传本地资料，然后在聊天框输入要求。
5. 检查 Plan，点击“确认执行”。执行期间保持 Chrome、侧栏和课程标签页打开。

每个浏览器拥有独立的任务和资料空间；Moodle 读取和修改发生在该用户自己的浏览器。重新打开插件会连接原工作区；清除插件数据或换浏览器会创建新工作区。管理员本机也可使用 `http://127.0.0.1:18791`。局域网 HTTP 不加密，请仅在可信网络使用；公网连接需要另外配置 HTTPS。

当前支持资料读取、分析和普通 Moodle 表单修改；远程排序移动、分组管理及 Moodle 资源上传尚未适配。
